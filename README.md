# ⚖️ 梅特勒天平自动录入助手 (by LLX)

**不用手抄，拒绝眼花！**
这款小工具可以把天平上的重量，自动填入 Excel 表格，或者任何你想要的地方。只需按一下键盘，数据自动上屏。

---

## 🔌 第一步：安装连接线的驱动

本工具配套的绿联的数据线（放在天平室的抽屉里）使用 **PL2303GT** 芯片。如果不装驱动，电脑可能无法识别天平。

**[驱动下载地址]**
[https://prolificusa.com/product/pl2303gt-usb-rs232-serial-bridge-controller-built-rs232-xcvr/](https://prolificusa.com/product/pl2303gt-usb-rs232-serial-bridge-controller-built-rs232-xcvr/)

- **🍎 Mac 用户**：

1. 请直接在 **App Store** (应用市场) 搜索下载 App：**`PL2303 Serial`**。
2. 打开该 App，按照提示去系统设置里允许扩展即可。

- **🪟 Windows 用户**：
  通常插入 USB 线后会自动安装。如果软件里找不到端口，请点击上方链接手动下载安装。

---

## ⚙️ 第二步：设置天平 (硬件，一般都设好了)

请检查天平屏幕上的设置，确保参数和电脑一致，否则连不上：

1. 找到天平设置中的`Peripheral` (Host)。
2. **核对以下参数**（不一样请修改并保存）：

- **Baud rate (波特率)**: `9600`
- **Bit/Parity**: `8 / No`
- **Stop bits**: `1`
- **Handshake**: `Xon/Xoff` (或者 None)

---

## 💻 第三步：打开软件

### 🪟 Windows 用户：

1. 双击 **`梅特勒天平助手.exe`**。
2. 如果是高分屏电脑，软件会自动开启高清模式。

### 🍎 Mac 用户 (重要！)：

1. 双击 **`梅特勒天平助手`** (黑色图标文件)。
2. **关于黑色窗口**：

- 软件启动后，会弹出一个**黑色的终端窗口**和一个**软件界面**。
- ⚠️ **请千万不要关闭那个黑色的窗口！** 它是软件运行的基础，最小化它即可。

3. **关于权限 (首次必读)**：

- 如果按 F9 没反应，请去 **系统设置** -> **隐私与安全性**。
- 分别在 **“辅助功能”** 和 **“输入监控”** 列表中，找到 **`终端 (Terminal)`**，确保两个开关都是 **[开启]** 状态。（同理如果你用其他有终端软件中运行，VScode， Pycharm, iTerm2, Warp...， 一样给他们权限）
- _设置完必须重启软件。_

---

## 🚀 第四步：开始使用

1. **连接天平**：

- 点击软件上的 **[刷新]** 按钮。
- 在“端口”里选择你的设备（通常是 `COM3` 或 `usbserial`）。
- 波特率选 `9600`，点击 **[打开连接]**。
- _看到底部显示绿色文字“已连接”即成功。_

2. **录入数据**：

- 打开 Excel，**用鼠标点击**你要录入的第一个格子（确保光标在闪烁）。
- 放好样品，关上天平门。
- 按下键盘上的 **`F9`** 键。

  > **笔记本小贴士**：如果按 F9 是调节音量或亮度，请尝试按 **`Fn + F9`**，也可以到设置中更改 F1—F12 功能键的用途。

- **滴！** 重量会自动填入表格并换行。

---

## 🛠 高级设置

- **修改快捷键**：习惯用 F10 或 F12？在“功能设置”里随时可以改。
- **不想自动回车？**：在“键入后缀”里改为 `Tab`（向右移）或 `无`。
- **只想复制？**：把模式改为 `复制到剪切板`，按下快捷键后数据会在你的剪贴板里，你可以去任意地方粘贴。

## ❓ 常见问题 (FAQ)

**Q: 软件打不开，提示“无法打开”或“损坏” (Mac)？**
A: 去系统设置 -> 隐私与安全性，往下翻到“安全性”区域，点击 **[仍要打开]**。

**Q: 点击“打开连接”报错？**

1. 线插紧了吗？
2. 驱动装了吗？
3. 是不是开了 CoolTerm 之类的软件占用了端口？请关闭其他串口工具。

**Q: 软件显示“收到数据”，但 Excel 里没反应？**
A: 你忘记 **用鼠标点击 Excel 单元格** 了。软件只会往“当前光标所在的地方”打字。

**Q: 读出来的数字是乱码？**
A: 天平设置里的“波特率”肯定不是 9600，请回到第二步重新设置天平。

**Q: 天平超时未响应？**
A: 天平还未平衡，需要等待平衡方可用快捷键读数（天平屏幕读数左侧的小圆圈消失）。
